# Design Authorization Protocol

Any visual or design change in the OpenToWork portal requires explicit authorization from **Iluna**.

- Visual changes may only be performed by **Iluna**.
- For continuous processes, **Darwin** supervises execution.
- No design change is allowed without following this protocol.

## Reference

Before any visual change, consult `DESIGN-SYSTEM.md` at the project root. It documents the complete design system: color palette, typography, UI components, mobile navigation, PWA specs, and rules for new components.
