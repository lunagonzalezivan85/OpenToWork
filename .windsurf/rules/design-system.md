# Design System Rules

## Reusable Components

- Create reusable components wherever code can be shared to avoid duplication.
- Colors are already well-defined in the postulant portal design — do not invent new ones.
- Every new UI must consume existing theme tokens (CSS variables).

## Color Palette — Postulant Portal

| Token / Use | Hex | Description |
|---|---|---|
| Card background | `#FFFFFF` | Pure white |
| Soft institutional banner | `#F0F7FF` | Very light navy blue |
| Royal blue (accent) | `#0066FF` | Brand primary |
| Main dark text | `#0B132B` | Deep navy for titles |
| Bluish gray intermediate | `#3A506B` | Roles, subtitles, chips |
| Neutral gray | `#778DA9` | Email, secondary text |
| Light blue background (pills) | `#E8F1FF` | Modality, active filters |
| Light gray background (chips) | `#F1F5F9` | Skills, neutral tags |
| Royal blue hover | `#0052CC` | Button hover |
