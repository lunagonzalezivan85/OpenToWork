# Skills de Claude Code del proyecto

Las siguientes skills son de **Emil Kowalski** ([emilkowalski/skill](https://github.com/emilkowalski/skill), licencia MIT, ver `LICENSE-emilkowalski`), copiadas del commit `e8a175d` (02-Oct-2026). Solo se incluyen las que aplican a una web (Blazor + CSS); se dejaron fuera las de iOS, Swift, Expo, movil nativo y Sonner (React).

| Skill | Que hace | Se activa |
|---|---|---|
| `emil-design-eng` | Criterio de pulido de UI: botones, formularios, popovers, accesibilidad y cuando/como animar | Sola, al trabajar en UI |
| `review-animations` | Revisa codigo de animaciones con un listón alto | Solo a mano: `/review-animations` |
| `improve-animations` | Auditoria de las animaciones existentes + planes de mejora (no toca codigo) | Sola o a mano |
| `find-animation-opportunities` | Busca donde falta movimiento y descarta donde sobra (no toca codigo) | Sola o a mano |
| `animation-vocabulary` | Traduce "el efecto ese de..." a su nombre tecnico | Sola |
| `break-ui` | Prueba una pantalla con datos extremos (nombres largos, cero items, emojis...) | Sola o a mano |
| `pick-ui-library` | Recomienda librerias de frontend (orientada a React) | Solo a mano: `/pick-ui-library` |

Para actualizarlas, volver a copiar las carpetas desde el repositorio original y anotar el commit aqui.
