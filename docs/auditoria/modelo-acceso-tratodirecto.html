La asimetría es la protección.
Buscar trabajo es público porque el que busca expone su propio interés, no datos de otros. Buscar candidatos está restringido porque expone datos de terceros que no eligieron aparecer — por eso ese sentido pasa por verificación + consentimiento + datos mínimos + entrega por staff.
